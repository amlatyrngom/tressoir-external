# System view: feedback

The system view is experimental. This file collects what gets in the way, so the kit can be
improved from real use. It is read from time to time and the lessons are applied to the skill and
its script in the kit.

Add one dated line per observation, newest first: what happened, and what would have helped.
Agents and I both write here. Do not fix the skill or the script inside this project; they are replaced on refresh.
